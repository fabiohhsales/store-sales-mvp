## 3️⃣ Fields da Classification

```
intent:  string
  • triagem       → Descobrir necessidade
  • qualificacao  → Coletar informações
  • agendamento   → Negociar horário
  • confirmacao   → Confirmar consulta
  • pos           → Pós-consulta
  • humano        → Transferência
  • outro         → Não detectou

stage:   string | null
  • Qualquer string (triagem, agendando, paciente, inativo, etc)
  • Mapeia para cadência: triagem→lead, agendando→lead, agendado→agendado

status:  string
  • pending   → IA respondeu, aguardando
  • open      → Humano precisa responder
  • resolved  → Conversa encerrada
```

## 🎓 Conceitos-Chave

```
Classification (nesta turn)
  ↓
  ├─ intent: O que quer (detecção)
  ├─ stage: Aonde está (contexto)
  └─ status: Próximo estado (decisão)
  
Labels (histórico acumulado)
  ↓
  └─ Array de tags: [etapa_triagem, lead_qualificado, ...]
  
Cadência (funil automático)
  ↓
  ├─ lead: D+1,2,3,5,7 (reengajamento)
  ├─ atendimento: D+1,2,4,7,10 (acompanhamento)
  └─ agendado: D-2, D-1, -3h, -5min (reminders)
```
